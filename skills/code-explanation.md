---
name: code-explanation
description: Load this skill when the user asks to explain, understand, or walk through Python code.
---

* Explain code for a scientist who knows their field but is still learning Python.
* Go step by step, in the order the code runs, not top to bottom if they differ.
* For each meaningful line or block, say in plain language *what* it does and *why* it is there.
* Avoid jargon. If a technical term is unavoidable (e.g. "list comprehension"), define it in one short sentence.
* Use analogies from everyday life when a concept is abstract.
* Point out the key idea or "trick" of the code, so the user learns the pattern, not just this example.
* End with a one-sentence summary of what the whole snippet accomplishes.
* If the code has a bug or a risky part, mention it gently after the explanation.
